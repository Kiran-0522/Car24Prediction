# Car24 Price Prediction 🚗📈

## 📌 Project Overview

This project aims to predict used car prices based on historical data from Car24.  
It includes exploratory data analysis (EDA), feature engineering, and model building using regression techniques.

---

## 🛠️ How to Use

1. Open `Car24_Price_Prediction(EDA+Model Building).ipynb` in Jupyter Notebook or VS Code.
2. Run the cells sequentially to explore data, preprocess features, and train the model.
3. Use `app.py` to deploy a basic prediction interface (optional).
4. Dataset used: `Car24_202212.csv`

---

## 📊 Features

- Exploratory Data Analysis (EDA) with visual insights  
- Feature selection and preprocessing  
- Regression model training and evaluation  
- Optional Streamlit/Flask app for prediction interface  
- Presentation file: `Car24predictor.pptx` included for summary

---

## 📦 Requirements

- Python 3.10+  
- Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn  
- Optional: streamlit or flask (for UI)
